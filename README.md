<h1>Shape Splitter</h1>

**Split every shape into equal halves**

Shape Splitter is a browser based game made using HTML, CSS and Javascript. 

**Play it here:**  https://rohanseshasaivasa.github.io/Shape_Splitter/

<img width="1365" height="604" alt="image" src="https://github.com/user-attachments/assets/bd8a72ed-8889-4020-913c-3396862f9a1a" />

## How to play

1. Press **Play** on the main menu
2. Shapes slide in from many directions. First they come fast and then slows down.
3. **Press, drag and let go** to draw a straight line across a shape
4. Your line must **start and end outside** the shape. A line that stops or starts inside a shape doesn't cut it.
5. The game measures both halves and shows the ratio of the split, like `48 / 52`.
6. Reach the level's goal before the ***60 seconds* run out.

## Scoring

| What happens | Points |
|---|---|
| Cut of **45 / 55** or better | **+1** |
| Cut worse than 45 / 55 | **−1** |
| A shape leaves the screen without being cut | **−1** |
| An exact **50 / 50** cut | +1 and a "Perfect!" |

On every level, shapes get a little smaller and move a little faster.
